# SALA Barber Shop

Στατική σελίδα: HTML + CSS + λίγη JavaScript. Ανοίγεις το `index.html` με διπλό κλικ.
Το design ακολουθεί την κάρτα του καταστήματος: ασπρόμαυρο, μαύρο προς λευκό με θόρυβο (grain), λογότυπο SALA.

## Design
- Χρώματα: στο `:root` του `styles.css` (ασπρόμαυρη παλέτα). Οι σκούρες ενότητες έχουν την κλάση `theme-dark`, ο θόρυβος την κλάση `grain`.
- Γραμματοσειρές: φάκελος `fonts/` (Cinzel και EB Garamond, άδεια SIL OFL, τοπικά για ταχύτητα και ασφάλεια).
- Λογότυπο και εικονίδια: σύμβολα SVG στην αρχή του `<body>` στο `index.html` (`#logo-sala`, `#swoosh`, `#i-pin`, `#i-phone`, `#i-insta`).
  Το λογότυπο είναι προσέγγιση της κάρτας. Αν ο γραφίστας δώσει το πρωτότυπο (SVG), αντικατάστησε το `<symbol id="logo-sala">`.

## Κρατήσεις με διαθεσιμότητα (Cal.com)
Η φόρμα δείχνει ημέρες και ελεύθερες ώρες ως κουμπιά. Η διαθεσιμότητα έρχεται από το Cal.com (δωρεάν).
1. Λογαριασμός στο cal.com ανά κατάστημα (ή ένας για όλα).
2. Ένα Event Type ανά υπηρεσία με τη σωστή διάρκεια (30/20/45 λεπτά) και το ωράριο στο Availability.
3. Στο `script.js`, στο `BOOKING`: `username` ανά κατάστημα και `slug` ανά υπηρεσία
   (από το link: `cal.com/sala-kentro/kourema` -> username `sala-kentro`, slug `kourema`).
4. Δοκίμασε μια κράτηση. Το ραντεβού εμφανίζεται στο ημερολόγιο Cal.com και ο πελάτης παίρνει email.

Όσο το `username` είναι κενό, η φόρμα είναι σε **λειτουργία δοκιμής**: οι ώρες βγαίνουν από το `demoHours`
και η κράτηση στέλνεται με WhatsApp (χωρίς έλεγχο για ήδη κλεισμένες ώρες).

## Τι αλλάζεις (ψάξε το ONOMA, ΠΟΛΗ, 210 000, Οδός, example.gr, Όνομα 1)
1. `index.html`: όνομα, πόλη, τηλέφωνα, διευθύνσεις, ωράρια, τιμές, links (Instagram, Google κριτικές), canonical και og:url (το domain σου).
2. Το JSON-LD στο head πρέπει να ταιριάζει ΑΚΡΙΒΩΣ με όσα φαίνονται στη σελίδα (NAP).
3. `script.js`: `WHATSAPP_NUMBER` (π.χ. 306912345678).
4. `styles.css`: χρώματα στο `:root`.

## Εικόνες που χρειάζονται (φάκελος `images/`)
- `hero.jpg` (1920x1080, κάτω από 300 KB)
- `share.jpg` (1200x630, για κοινοποίηση)
- `work-1.jpg` έως `work-6.jpg` (600x600, WebP ή JPG)
Ονόματα: μόνο λατινικά, μικρά, με παύλες.
